# ノート記述ルール（Note Rules）

本ディレクトリ（`src/note/`）配下のノートファイルを作成・更新する際の記述ルールおよび方針のまとめです。ユーザーからの指示に基づき、今後のノート作成・編集時は本ルールを遵守します。

---

## 1. 普遍的・汎用的な知識のみを記載する
- **記載対象（含めるもの）**:
  - マインクラフト本体の物理演算、空間幾何、ティック処理順序などの根幹仕様
  - Script API 全体に共通して影響する仕様・挙動、および既知のバグ（Mojang バグ番号等）とその幾何学的・物理的な回避策
  - 他のアドオンや今後の開発でも普遍的に再利用できる物理法則・数学的知見
- **除外対象（含めないもの）**:
  - 特定アドオン内部の独自コード情報（プロジェクト固有の関数名、変数名、型定義、ファイル構成など）
  - 局所的にしか使えない単発APIやメソッドの解説（例: `getMovementVector()` の使い方や個別仕様など）
  - 実装上の個別都合によるモード設計やローカルフラグの解説

---

## 2. 新規仕様判明時の即時記録
- 実装や検証の過程でマインクラフトの仕様に関して新しく判明した事実や落とし穴があれば、該当するノートへ速やかに記録・更新する。

---

## 3. 本ルールの更新方針
- ユーザーからノートの記述方法や方針に関して新たな命令・指示があった場合、随時本ファイル（`src/note/note-rule.md`）にその内容をまとめて蓄積・更新していく。
